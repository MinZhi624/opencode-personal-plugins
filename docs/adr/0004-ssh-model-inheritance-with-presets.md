# SSH 默认模型跟随已应用的角色预设

上游新增了可应用的角色模型预设，而 SSH 扩展原本继承对应本机角色的模型。此次整合继续使用这一关系：应用预设后，未显式指定模型的 SSH 角色跟随对应角色的新模型及其变体；显式 SSH 模型配置优先，不被预设继承值覆盖。

这项变更作用于角色默认值，供新会话和后续新派发 Worker 使用，不主动修改已有会话的模型。不另建一套 SSH 专用预设，也不只在插件启动时固定继承快照。

## 验证边界

当前 SSH 代码在角色转换回调内读取对应角色的模型，上游在应用预设时请求重新加载角色；仅凭这些源码事实不能证明所有转换都会按预期顺序重新执行。实施时应在独立、隔离的真实 OpenCode 运行环境中，检查应用预设前后的有效角色配置及显式覆盖优先级，不调用模型、不连接真实 SSH、不操作共享服务。

如果现有加载流程已经满足要求，只补充聚焦验证，不另造同步机制。若需要修复，只允许必要的兼容适配；不得为此扩展成新的模型预设系统，也不得把模拟回调执行当作真实运行验收。

本决策确认目标行为，不表示已实施或已通过运行验证。相关领域用语见仓库根目录的 `CONTEXT.md`。
